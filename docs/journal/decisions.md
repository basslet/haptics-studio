# Decisions

- No Contributor License Agreement. Contributions are licensed under the repository license, which keeps contributing simple.
- Doc pages link directly across the three repositories (Studio, SDK, examples), which read as one suite.
- Every page a reader opens starts with one navigation block for the whole suite, with the current page marked, and has none at the bottom (#32). A page with no entry of its own marks the section whose `README.md` sits above it; a page outside every section, such as a component README, marks nothing (#42). `AGENTS.md`, the journal and `release-notes.md`, which the app shows under View > Show Changelog, carry no block. `scripts/doc_nav.js` generates it and `yarn docs:lint` checks it; both scripts and their tests are the same files in all three repositories, so the pages of all three cannot drift apart. Each repository's lint proves that its own entries exist on the branch it runs on. Links from the other repositories go to `main`, so a page linked before it reaches `main` there returns 404 until it does. The SDK's Documentation sub-pages are not in the block; the SDK's Documentation page lists them.
- This project publishes no Quest build of the companion app; the docs link to Meta's download.
- Download and platform text stay placeholders until signed builds exist, so the docs never state an unverified value.
- The README is the Overview page. Designer pages sit under Design & Integration: Getting Started, Feature Walkthrough, Haptics Guidelines and Resources. A section with subpages is a folder whose `README.md` is the section's page, so the navigation block marks the section on each subpage.
- Haptic design guidance is split by depth. Studio's Haptics Guidelines page holds one page of guidance that applies on every platform; guidance for one platform, longer guides and worked examples live in Haptics Studio Examples. Studio's Resources page is the only list of outside documentation in the three repositories; the other two link to it.
- Studio's documentation has no troubleshooting pages. Bugs go to GitHub issues.
- A link to a page that lives next to the code (a component `README.md`) points at its folder, so GitHub shows the code with the README below it. Such a page marks no entry in the navigation block (#42).
- `CODE_OF_CONDUCT.md` holds the Code of Conduct; `CONTRIBUTING.md` holds how to contribute and where to start in the code; Source Code (`docs/building.md`) holds build, run and test.
