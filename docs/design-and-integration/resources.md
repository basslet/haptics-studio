# Resources

Haptics documentation from the makers of each platform and tool. This is the one list of outside documentation for Haptics Studio, the Haptics SDK and Haptics Studio Examples; other pages link here. Which export format suits each target is in [Export Formats](README.md#export-formats).

## Android

- [Haptics with PWLE](https://source.android.com/docs/core/interaction/haptics/haptics-pwle) (Android Open Source Project). PWLE support in the Haptics SDK is in progress.

## iOS

- [Core Haptics](https://developer.apple.com/documentation/corehaptics) (Apple)

## Meta Quest

- [Haptics design overview](https://developers.meta.com/horizon/design/haptics-overview/) (Meta)

## PlayStation

Sony's documentation for DualSense haptics is open only to registered PlayStation partners. Haptics Studio exports rendered audio (PCM) that DualSense can play; it cannot audition on PlayStation.

## Unity

- [Haptics SDK for Unity](https://developers.meta.com/horizon/documentation/unity/unity-haptics-sdk/) (Meta)

## Unreal Engine

- [Haptics SDK for Unreal](https://developers.meta.com/horizon/documentation/unreal/unreal-haptics-sdk/) (Meta)

## OpenXR

- [xrApplyHapticFeedback](https://registry.khronos.org/OpenXR/specs/1.1/man/html/xrApplyHapticFeedback.html) (Khronos)
- [XR_EXT_haptic_parametric](https://registry.khronos.org/OpenXR/specs/1.1/man/html/XR_EXT_haptic_parametric.html) (Khronos), an extension that is not ratified

## FMOD

- [Haptics Instrument](https://www.fmod.com/docs/2.03/studio/instrument-reference.html#haptics-instrument) (Firelight Technologies)

## Wwise

- [Haptic Clip Player](https://www.audiokinetic.com/en/public-library/2025.1.12_9287/?source=Help&id=haptic_clip_player_plug_in) (Audiokinetic)
