# Findings — haptics-studio

## 2026-11-04 — finding: what the checkout token must do

- what: `actions/checkout` v4 passes `token` as the credential for the repository fetch and for submodules, so it must read both private repos; that it fetches the app repo too is read from the README and `src/git-auth-helper.ts`, not observed. Fine-grained tokens "always include read-only access to all public repositories", which covers the SDK's public nested submodules; expiry is "1 to 366 days or `none`", default 30. Secrets "are not passed to the runner when a workflow is triggered from a forked repository", and "Secrets are not available to workflows triggered by Dependabot events". The docs do not state that Contents read is what a clone needs: the first CI run settles it.
- why: `token` is a request parameter this repo never sent, and a deploy key will likely not work, because `.gitmodules` uses an https URL and no https-to-ssh rewrite was found.
